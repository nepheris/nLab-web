# Conventions de nommage — nLab Icon Library

## Fichiers
Toujours en kebab-case : `folder-open.svg`, `sort-desc.svg`, `pdf-studio.svg`.

## IDs techniques
Les IDs historiques du Studio Core peuvent rester en camelCase pour compatibilité : `rotateLeft`, `headerFooter`, `dragHandle`.
Le manifest fournit alors un alias kebab-case.

## Familles
- studio-icons : identité de Studio.
- function-icons : action métier.
- filetype-icons : type/famille de fichier.
- ui-icons : état ou contrôle d’interface.
- symbology-icons : QR et codes-barres.

## Variantes
Utiliser des suffixes explicites : `-open`, `-closed`, `-on`, `-off`, `-asc`, `-desc`, `-left`, `-right`.
