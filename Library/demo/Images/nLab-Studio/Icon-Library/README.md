# nLab Studio Icon Library

Bibliothèque canonique des SVG nLab.

## Structure
- `studio-icons/`
- `function-icons/`
- `filetype-icons/`
- `ui-icons/`
- `symbology-icons/`
- `manifests/`
- `docs/`
- `gallery/`

## Source runtime
Les applications utilisent les copies runtime sous `assets/studios/` et `assets/icons/`.
Cette arborescence est la référence documentaire et de démonstration.

## Documentation
- Mini-charte : `docs/mini-charte-iconographique-nlab.md`
- Prompt de génération/revue : `docs/icon-generation-prompt.md`
- Nommage : `docs/naming-conventions.md`

## Manifest
`manifests/index.json` référence toutes les familles et leurs manifests détaillés.
