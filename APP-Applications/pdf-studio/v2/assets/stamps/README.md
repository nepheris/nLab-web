# Tampons SVG PDF Studio V2

Ces SVG sont monochromes, sans fond et utilisent `currentColor`.

Pour modifier la couleur en CSS, injecter le SVG inline :

```css
.stamp-preview { color: #C62828; }
```

Les matrices `matrice-circulaire.svg`, `matrice-ligne.svg` et `matrice-multiligne.svg`
servent de bases au générateur de tampons de PDF Studio V2.
