Le moteur qpdf WebAssembly est chargé uniquement à la demande. Le document reste dans le navigateur. Le mot de passe utilisateur impose l’ouverture ; le mot de passe propriétaire contrôle les permissions.
Les restrictions d’impression/modification sont des permissions PDF appliquées par les lecteurs conformes ; elles ne remplacent pas le chiffrement par mot de passe d’ouverture.
