# PDF Studio V1 — revue opérateur du 2026-09-29

Source reviewed: public PDF Studio V1 TEST.

## Acceptance principle

The current V1 layout/ribbon/sidebar direction is retained. The main work is:
1. regression recovery against the 0.9.20–0.9.25 TEST line;
2. UX clarification;
3. convergence with the newer OCR, Code and Image Studios.

A checked feature in the old master checklist means code may exist; it does **not** mean HUMAN-00 interaction acceptance.

## Accepted direction

- overall V1 presentation, ribbon and sidebar structure;
- local input, multi-file and folder loading;
- selected-page scope: current / checked / whole document;
- output/classification direction;
- named-variable/template concept;
- optimization parameters concept;
- import/export stamp library concept.

## P0 — workspace and navigation

- separate 1.1 Source from 1.2 Selected files;
- previous/next loaded-file navigation with viewer synchronization;
- sorting by name/path/type/size/page count;
- Selected files shortcut in ribbon;
- local computer is default input;
- Google Drive shown as DEVELOPMENT until live OAuth acceptance.

## P0 — page strip regression recovery

- add-page tile at end of thumbnails;
- red delete control on each page;
- drag/drop page reorder;
- preserve checkboxes and common scope selector.

## P0 — common object manipulation engine

Revalidate and recover the manipulation engine for:
- stamps;
- text;
- highlight;
- pen;
- inserted images;
- visual signatures;
- QR/barcodes.

Common capabilities where applicable:
- select;
- drag/move;
- resize;
- free rotation;
- ±90° rotation shortcuts;
- delete;
- object-specific parameters;
- history entry;
- preview refresh.

Image and signature objects additionally need:
- crop;
- aspect-ratio handling;
- mirror horizontal/vertical;
- DPI / quality processing;
- shared image engine reuse.

## P0 — stamps

- visible contextual stamp tools when Stamp is active;
- STAMP_DATE + DATE_A/B/C/D with contextual help;
- stamp template/model;
- linked output prefix/suffix;
- direct placement on PDF;
- move/resize/rotate after insertion;
- import/export stamp library.

## P0 — contextual help

Add ? help for:
- every named variable;
- five stamp dates;
- initials/client/project/reference/site/service/category/tag/treatment;
- input/source and selected files;
- destination/classification/templates;
- DPI/JPEG/grayscale;

## P0 — convergence with OCR Studio

Import improvements validated/developed in OCR Studio:
- preview refresh when file changes;
- image preview and PDF preview appropriate to input type;
- zoom in/out/fit;
- explicit refresh;
- editable OCR text post-processing;
- undo/redo/reset OCR text;
- contextual help for engine/language/output;
- Tesseract as validated text OCR engine;
- OCRmyPDF identified as searchable-PDF orchestration rather than a second generic text engine.

## P0 — convergence with Code Studio

PDF Studio must consume the shared Code Engine rather than maintain a separate degraded QR implementation.

Target:
- QR;
- Data Matrix;
- Aztec;
- PDF417;
- Code128/Code39/EAN/UPC/ITF/Codabar;
- foreground/background color picker + hexadecimal value;
- scale/output size;
- advanced QR styling when the selected format supports it;
- module/dot style;
- central logo/image with safe error-correction constraints;
- PNG/SVG output;
- decode/read capability;
- contextual help per code format and parameter.

## P0 — convergence with Image Studio

Reuse the shared Image Engine for inserted images and image workflows:
- quick ±90° rotations;
- free rotation from -360° to +360°;
- horizontal/vertical mirror;
- resize with optional aspect lock;
- graphical crop;
- source/result zoom;
- PNG/JPEG/WebP conversion;
- quality and DPI;
- grayscale, denoise, deskew and OCR preprocessing;
- visible watermark using the same movable-object UX as PDF stamps: text/image/SVG/logo, position, size, opacity, rotation, margin;
- simple invisible local image mark with encode/read/verify; **not** a web tracking pixel;
- EXIF/metadata inspect/edit/delete/import/export.

## P1 — signatures

- local signature image and drawn signature;
- common object engine for move/resize/rotate;
- external cryptographic DSS/PAdES remains DEVELOPMENT until real provider acceptance;
- no credential/secret committed to the public repository.

## P1 — optimization

- confirm common scope is actually wired;
- explain DPI ranges contextually;
- preview before/after;
- show source size and estimated/result size;
- show compression delta.

## P1 — output and templates

- custom output path/name templates editable;
- contextual variable help;
- save templates into personal JSON profile;
- import/export templates;
- output extensions and operation suffixes remain reusable.

## DEVELOPMENT / yellow state

Until separately accepted:
- live Google Drive OAuth/Picker;
- external DSS/PAdES;
- high-fidelity office conversion;
- advanced PDF forms;
- conversion workflows not yet interaction-tested.

## Common Studio framework consequence

These improvements must be implemented in shared Studio V1 modules whenever the behavior is not PDF-specific:
- StudioShell;
- FileWorkspace / selected-files navigation;
- ActionHistory;
- ContextHelp;
- OutputService;
- Template/Variable engine;
- object manipulation primitives where practical.

OCR Studio, Code Studio and Image Studio should migrate to the same shell after these common blocks are stable.
