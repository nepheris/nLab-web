Signer / parapher

Mini-app dérivée de PDF Studio. Elle réutilise le moteur PDF et le profil personnel Studio Core ; seules les fonctions nécessaires à la signature rapide sont exposées.

Chargez un PDF pour commencer.

La signature visuelle n’est pas une preuve cryptographique. Pour PAdES/certificat/DSS, ouvrez PDF Studio.
