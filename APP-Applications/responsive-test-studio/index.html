Ce qui est réellement testé

L’iframe reçoit les dimensions CSS sélectionnées. Les media queries et comportements responsive de la page s’appliquent dans cet espace. Le zoom réduit seulement la représentation de l’écran pour qu’elle tienne sur votre ordinateur.

Certains sites externes interdisent leur intégration en iframe par sécurité. Les contrôles des permissions, de la caméra, du clavier virtuel, du défilement tactile et d’Android Chrome nécessiteront une couche de tests supplémentaire, puis un véritable appareil.
