# Scan2D — corpus de validation V1

Le corpus de tests de l'extension Scan2D d'Image Studio est administré dans le dépôt source canonique :

https://github.com/nepheris/nLab/tree/main/Build/APP-Application/APP17-image-studio/tests/scan2d/v1

Le dossier inclut l'index, le manifeste des 7 essais et le SVG nominal. **Les 7 fichiers PNG et l'archive ZIP doivent encore être transférés** : le dépôt ne contient pas encore le corpus binaire complet.

Pour ajouter un nouveau test, placer l'image et compléter le manifeste dans ce dossier source, puis mettre à jour ce pointeur web au besoin. Ne pas dupliquer les ressources entre les deux dépôts.
