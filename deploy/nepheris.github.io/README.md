# nepheris.github.io — page racine préparée

Source canonique du futur portail utilisateur GitHub Pages `https://nepheris.github.io/`.

## État

Le dépôt utilisateur `nepheris/nepheris.github.io` n'existe pas encore. GitHub exige ce nom exact pour servir la racine `https://nepheris.github.io/`.

## Déploiement

1. créer un dépôt **public** nommé exactement `nepheris.github.io` sous le compte `nepheris` ;
2. copier ce `index.html` à la racine du nouveau dépôt ;
3. ajouter un fichier `.nojekyll` à la racine ;
4. conserver `main` comme branche par défaut et activer GitHub Pages si nécessaire.

Le portail référence uniquement des projets publics et peut ensuite être enrichi à mesure que de nouveaux sites sont publiés.
