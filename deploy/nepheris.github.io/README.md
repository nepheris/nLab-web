# nepheris.github.io — page racine préparée

Le dépôt utilisateur GitHub Pages `nepheris/nepheris.github.io` n'existe pas encore.

Pour activer `https://nepheris.github.io/` :

1. créer un dépôt **public** nommé exactement `nepheris.github.io` ;
2. copier le fichier `index.html` de ce dossier à la racine du nouveau dépôt ;
3. conserver la branche `main` ;
4. GitHub Pages sert normalement automatiquement le dépôt utilisateur à l'URL racine.

La page pointe vers nLab Web, nLab Studios et PDF Studio et utilise les assets canoniques du branding nLab publiés dans `nLab-web/assets/branding/`.
